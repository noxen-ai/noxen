Getting Started
Noxen is a local AI orchestrator for multi-repo development. It analyzes your codebase, generates improvement plans, and writes code autonomously using a Board of LLM providers.
Installation
Clone the repository and set up your environment:
$ git clone https://github.com/noxen-ai/noxen.git $ cd noxen $ cp .env.example .env $ docker-compose up -d
Authentication
Authenticate the CLI with your Noxen account:
$ noxen auth # A browser window will open for authorization # Once confirmed, your credentials are saved locally
First Project
Register your project and run the first analysis:
$ cd /path/to/your/project $ noxen project add . $ noxen start
This runs the Spider Analysis, which scans your codebase and generates a comprehensive report available in the Reports section.
CLI Reference
All available CLI commands and their usage.
CommandDescription
noxen authAuthenticate with your Noxen account via browser-based device flow
noxen project add .Register the current directory as a Noxen project
noxen startRun Spider Analysis on the registered project, generating a full report
noxen generate-codeExecute an approved action plan, writing code changes to your project
noxen statusCheck the status of Noxen services and current project
noxen researchStart an interactive research session using the knowledge base
API Reference
Noxen exposes a REST API on port 8400. All authenticated endpoints require the X-Session-Token header.
Authentication
EndpointDescription
POST /api/auth/registerCreate a new account (name, email, password)
POST /api/auth/loginSign in and receive a session token
GET /api/auth/meGet current user info
POST /api/auth/logoutInvalidate session token
Projects
EndpointDescription
GET /api/projects/List all registered projects
POST /api/projects/registerRegister a new project
POST /api/projects/{name}/indexIndex project into knowledge base
Reports & Plans
EndpointDescription
GET /api/auth/reportsList all Spider Analysis reports
GET /api/auth/reports/{id}Get report detail
POST /api/auth/plans/generateGenerate an action plan from a report
POST /api/auth/plans/{id}/approveApprove a plan for execution
Chat & Research
EndpointDescription
POST /api/auth/chatSend a RAG chat message about a project
GET /api/auth/conversationsList all conversations
GET /api/auth/historyGet execution history
Configuration
Noxen is configured via the .env file. Key variables:
VariableDescription
NOXEN_LICENSE_KEYYour API key (from Dashboard or noxen auth)
OPENAI_API_KEYOpenAI API key for Board deliberation
ANTHROPIC_API_KEYAnthropic API key for Board deliberation
OLLAMA_BASE_URLOllama endpoint (default: http://localhost:11434)
QDRANT_URLQdrant vector database URL (default: http://localhost:6333)
NOXEN_HOSTServer bind address (default: 0.0.0.0)
NOXEN_PORTServer port (default: 8400)
LLM Providers
The Noxen Board requires at least 2 LLM providers for deliberation. Configure providers in Settings or via the .env file. Supported providers: OpenAI (GPT-4), Anthropic (Claude), Ollama (local models).
Architecture
Noxen consists of several core components working together:
Spider Analysis
Crawls your codebase detecting languages, frameworks, services, dependencies, and complexity metrics. Results are stored as reports.
Board Deliberation
Multiple LLM providers analyze your code independently, then deliberate to produce consensus-driven improvement plans.
Knowledge Base
Powered by Qdrant vector database. Your code is chunked, embedded, and indexed for semantic search during RAG chat and code generation.
Code Generation
Executes approved plans by writing code changes directly to your project files, with full audit trail in the execution history.
